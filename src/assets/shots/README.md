Screenshots for the Idea Graveyard modals.

Drop images in a folder named after the idea's `id` in Graveyard.jsx:

  shots/playerpairs/01-swipe.png
  shots/playerpairs/02-map.png
  shots/pitchwise/01.png

Filename order = display order. png/jpg/jpeg/webp. No code changes needed —
an idea with no folder simply shows no gallery.
